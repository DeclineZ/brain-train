# Games Overview (21 Games)

| Game ID | Name (ชื่อเกม) | Category (หมวดหมู่) | Short Description (คำอธิบายสั้น) | Long Description (คำอธิบายยาว) |
| :--- | :--- | :--- | :--- | :--- |
| `game-01-cardmatch` | Card Match (จับคู่การ์ดความจำ) | Memory (ความจำ) | จำตำแหน่งรูปสัตว์บนการ์ด แล้วเปิดจับคู่รูปที่เหมือนกันทั้งหมดให้ครบ | เกมฝึกความจำระยะสั้น (Short-term Memory & Spatial Memory) ผู้เล่นต้องเปิดดูการ์ดรูปสัตว์ต่างๆ ที่คว่ำอยู่ จำตำแหน่งของแต่ละรูป และเปิดการ์ดที่มีรูปภาพเหมือนกันให้ครบทุกคู่ภายในจำนวนรอบหรือเวลาที่กำหนด |
| `game-02-sensorlock` | Sensor Lock (สวิตช์สมาธิ) | Speed & Focus (ความเร็วและสมาธิ) | ตัดสินใจอย่างรวดเร็วว่าลูกศรและข้อความทิศทางตรงกันหรือไม่ | เกมฝึกสมาธิและการกดตอบสนองอย่างรวดเร็ว (Stroop Effect & Inhibition) ผู้เล่นต้องเปรียบเทียบทิศทางของลูกศรกับข้อความทิศทาง (เช่น บน ล่าง ซ้าย ขวา) แล้วตัดสินใจว่า "ตรง" หรือ "ไม่ตรง" โดยเกมจะเพิ่มเงื่อนไขคำปฏิเสธ (เช่น "ไม่ใช่บน") และสลับตำแหน่งปุ่ม |
| `game-03-billiards-math` | Billiards Math (บิลเลียดคณิตศาสตร์) | Calculation (การคำนวณ) | ยิงลูกบิลเลียดตัวเลขลงช่องสมการให้ถูกต้องตามโจทย์คณิตศาสตร์ | เกมฝึกทักษะการคำนวณและการวางแผนเชิงมิติ (Calculation & Spatial Planning) ผู้เล่นต้องเล็งทิศทางและยิงลูกบิลเลียดตัวเลขบนโต๊ะให้เข้าช่องคำตอบของสมการคณิตศาสตร์อย่างถูกต้อง ทันเวลา และหลบหลีกอุปสรรคกับดักบนโต๊ะบิลเลียด |
| `game-04-floating-ball-math` | Floating Ball Math (เรือคณิตลอยน้ำ) | Calculation & Memory (การคำนวณและความจำ) | ควบคุมเรือเก็บบอลตัวเลขลอยน้ำเพื่อสะสมคำตอบให้ตรงตามโจทย์สมการ | เกมฝึกการคิดคำนวณและสมาธิการทำงานของสมอง (Working Memory & Executive Functioning) ผู้เล่นต้องเลื่อนเรือไปใน 3 เลนเพื่อเก็บบอลตัวเลขลอยน้ำ นำมาคำนวณบวกลบคูณหารให้ตรงเป้าหมายสมการ พร้อมหลบหลีกสิ่งกีดขวางและจอมขโมยบอล |
| `game-05-wormtrain` | Worm Train (สับรางหนอนน้อย) | Planning (การวางแผนและแก้ปัญหา) | สับรางสวิตช์ทางเดินใต้ดินเพื่อส่งหนอนสีต่างๆ ไปยังหลุมที่มีสีตรงกัน | เกมฝึกการวางแผนเชิงตรรกะและมิติสัมพันธ์ (Logical Planning & Route Management) ผู้เล่นต้องกดสลับทิศทางสวิตช์บนเส้นทางใต้ดิน เพื่อเปลี่ยนทิศทางการเลื้อยของรถไฟหนอนหลากสี ให้เข้าสู่หลุมที่มีสีเดียวกันอย่างถูกต้อง หลบหลีกกับดักและการชนกัน |
| `game-06-dreamdirect` | Dream Direct (ทิศทางเนรมิต) | Attention & Speed (สมาธิและความเร็ว) | กดปุ่มทิศทางให้ตรงตามชนิดของลูกศรที่เลื่อนลงมาตามจังหวะ | เกมฝึกสมาธิ การยับยั้งชั่งใจ และการเลือกตอบสนอง (Selective Attention & Impulse Control) ผู้เล่นต้องกดปุ่มทิศทางให้ถูกต้องตามชนิดลูกศรที่เลื่อนลงมา เช่น ลูกศรสมอเรือ (กดทิศเดิม) หรือลูกศรนักสำรวจ (กดทิศตรงข้าม) พร้อมลูกศรหมุนและลูกศรคู่ |
| `game-07-pinkcup` | Pink Cup (แก้วสีชมพู) | Memory & Planning (ความจำและการวางแผน) | เลื่อนแก้วสีชมพูไปยังเป้าหมาย พร้อมจดจำตัวเลขที่ซ่อนอยู่ใต้แก้ว | เกมฝึกความจำมิติสัมพันธ์และการวางแผนเส้นทาง (Spatial Awareness & Working Memory) ผู้เล่นต้องสลับตำแหน่งแก้วสีชมพูไปยังช่องเป้าหมายด้วยจำนวนก้าวที่น้อยที่สุด พร้อมทั้งจำตัวเลขที่แอบเผยออกมาใต้แก้วแต่ละใบ เพื่อตอบคำถามทดสอบความจำเมื่อถึงเป้าหมาย |
| `game-08-mysterysound` | Mystery Sound (เสียงปริศนา) | Language & Auditory (ภาษาและการฟัง) | ฟังเสียงสัตว์และแยกแยะระบุชื่อสัตว์ให้ถูกต้องตามลำดับและจำนวน | เกมฝึกการฟังและการจดจำเสียง (Auditory Processing & Verbal Memory) ผู้เล่นฟังเสียงสัตว์ (เสียงเดี่ยว, หลายตัว หรือเสียงซ้อนกัน) แล้วแยกแยะว่ามีเสียงสัตว์ชนิดใดบ้าง โดยเลือกตัวเลือกภาพและชื่อสัตว์ให้ถูกต้อง |
| `game-09-tube-sort` | Tube Sort (แยกสีในหลอดแก้ว) | Planning (การวางแผนแก้ปัญหา) | เทลูกบอลสีสลับหลอดแก้วเพื่อคัดแยกให้แต่ละหลอดมีสีเดียวกันล้วน | เกมปริศนาฝึกการวางแผนและแก้ปัญหาเชิงตรรกะ (Logical Reasoning & Task Planning) ผู้เล่นต้องย้ายลูกบอลสีระหว่างหลอดทดลอง โดยวางบอลสีเดียวกันทับกันหรือใส่หลอดว่าง จัดเรียงให้แต่ละหลอดมีลูกบอลสีเดียวกันล้วนทุกหลอด |
| `game-10-miner` | Gold Miner (คนขุดแร่) | Visual & Timing (มิติสัมพันธ์และจังหวะ) | กะจังหวะปล่อยตะขอเพื่อขุดแร่ทองคำและอัญมณีมีค่า หลบหลีกก้อนหิน | เกมฝึกการกะจังหวะและการรับรู้มิติสัมพันธ์ (Spatial Timing & Hand-Eye Coordination) ผู้เล่นต้องกะจังหวะการแกว่งของตะขอเพื่อปล่อยตะขอไปดึงแร่ทองคำ อัญมณี และขุมทรัพย์ใต้อินทรีย์ โดยต้องคำนวณทิศทางและระยะทางเพื่อหลบหลีกก้อนหินหนัก |
| `game-11-pipe-patch` | Pipe Patch (ซ่อมท่อน้ำ) | Visual & Planning (มิติสัมพันธ์และการวางแผน) | หมุนและเลือกชิ้นส่วนท่อมาวางต่อเชื่อมจากจุดเริ่มต้นไปยังจุดปลายทาง | เกมฝึกการแก้ปัญหาเชิงมิติสัมพันธ์และการวางแผน (Spatial Problem Solving & Path Planning) ผู้เล่นต้องเลือกชิ้นส่วนท่อน้ำรูปทรงต่างๆ (ท่อตรง ข้องอ ท่อสามทาง) มาต่อเชื่อมเส้นทางให้น้ำไหลจากจุดเริ่มต้นไปยังเป้าหมาย โดยต้องหลบหลีกกำแพงและอุปสรรค |
| `game-12-gridhunter` | Grid Hunter (นักล่าตารางเลข) | Speed & Focus (ความเร็วการคิดและสมาธิ) | ค้นหาและกดเลือกตัวเลขบนตารางตามเงื่อนไขให้เร็วที่สุด (เช่น เลขน้อยสุด เลขคู่/คี่) | เกมฝึกความเร็วในการประมวลผลและการกวาดสายตา (Processing Speed & Visual Search) ผู้เล่นต้องสแกนตารางตัวเลขและกดเลือกตัวเลขที่ถูกต้องตามกฎเงื่อนไขที่เปลี่ยนไปเรื่อยๆ (เช่น เลขค่าน้อยที่สุด เลขคู่ เลขคี่ หรือเลขค่ามากที่สุด) พร้อมหลบการ์ดกับดัก |
| `game-13-boxpattern` | Box Pattern (ความจำกล่องไฟ) | Memory (ความจำ) | จำลำดับการสว่างของกล่องไฟ แล้วกดเรียงลำดับให้ถูกต้องตามที่เห็น | เกมฝึกความจำมิติสัมพันธ์แบบเป็นลำดับขั้น (Spatial Sequential Memory & Visuospatial Working Memory) ผู้เล่นต้องสังเกตรูปแบบและลำดับการเปล่งแสงของกล่องไฟบนกระดาน แล้วกดเลือกกล่องไฟย้อนกลับตามลำดับให้ถูกต้องแม่นยำ |
| `game-14-wordrecognize` | Word Recognize (จำคำศัพท์) | Memory (ความจำ) | ระบุว่าคำศัพท์ที่ปรากฏบนหน้าจอเคยเห็นแล้วในรอบนี้ หรือเป็นคำใหม่ | เกมฝึกความจำในการจดจำคำศัพท์ (Verbal Recognition Memory & N-Back Memory) คำศัพท์จะปรากฏขึ้นทีละคำ ผู้เล่นต้องตัดสินใจให้ถูกต้องว่าคำนั้นเป็นคำ "ใหม่" ที่ยังไม่เคยเจอในเกมรอบนี้ หรือเป็นคำที่ "เคยเห็น" มาก่อนแล้ว |
| `game-15-taxidriver` | Taxi Driver (แท็กซี่จอมเลี้ยว) | Visual & Navigation (มิติสัมพันธ์และการนำทาง) | ขับรถแท็กซี่ไปตามเส้นทางเมือง เลี้ยวทิศทางซ้าย/ขวา/ตรง ให้ถูกต้องตามมุมมองของรถ | เกมฝึกมุมมองมิติสัมพันธ์และการนำทาง (Egocentric Spatial Navigation & Perspective Taking) ผู้เล่นรับบทขับรถแท็กซี่และตัดสินใจเลี้ยว (เลี้ยวซ้าย เลี้ยวขวา หรือตรงไป) ตามมุมมองของคนขับเมื่อถึงทางแยก โดยต้องประเมินทิศทางให้ถูกต้องจากมุมมองในรถ |
| `game-16-doorguardian` | Door Guardian (คนเฝ้าประตู) | Attention & Reasoning (การสังเกตและประยุกต์ใช้กฎ) | ตรวจสอบความถูกต้องของผู้ขอเข้าประตูตามกฎคู่มือแล้วเลือกลงมติ อนุญาต หรือ ปฏิเสธ | เกมฝึกการตรวจสอบรายละเอียดและการประยุกต์ใช้กฎ (Rule Evaluation & Attention to Detail) ผู้เล่นทำหน้าที่เป็นคนเฝ้าประตู ตรวจสอบผู้มาเยือนแต่ละคนเทียบกับกฎและภาพอ้างอิงในคู่มือ (เช่น ตัวละครที่ได้รับอนุญาต หรือจุดผิดปกติผิดแปลก) เพื่อกดปุ่ม "อนุญาต" หรือ "ปฏิเสธ" |
| `game-17-floatingmarket` | Floating Market (ตลาดน้ำจอมเก็บ) | Focus & Categorization (สมาธิและการคัดแยกหมวดหมู่) | พายเรือเก็บสินค้าในตลาดน้ำเฉพาะชนิดที่ตรงตามเงื่อนไข หลบหลีกสิ่งกีดขวาง | เกมฝึกการเลือกตอบสนองและการคัดแยกหมวดหมู่ (Selective Attention & Category Filtering) ผู้เล่นพายเรือในตลาดน้ำเพื่อเก็บสินค้าชนิดเฉพาะ (เช่น ผลไม้สีเหลือง, ขนมหวาน, หรือของราคาไม่เกินกำหนด) ที่ลอยมาในลำน้ำให้ตรงตามโจทย์เงื่อนไข พร้อมหลบสิ่งกีดขวาง |
| `game-18-runforyourlife` | Run For Your Life (วิ่งสู้ชีวิต) | Focus & Speed (สมาธิการตอบสนองและความเร็ว) | วิ่งหลบสิ่งกีดขวางบน 5 เลน สลับเลน ยิงปืน และเก็บไอเทมพาวเวอร์อัป | เกมวิ่งวิบากตอบสนองความไว (Endless Runner & Rapid Reflexes) ผู้เล่นต้องสลับเลนไปซ้าย-ขวาบนลู่วิ่ง 5 เลนเพื่อหลบสิ่งกีดขวางที่เข้ามาอย่างรวดเร็ว สามารถเก็บเหรียญ ไอเทมพิเศษ (แม่เหล็ก ร่างโปร่งแสง ชะลอเวลา) และใช้ปืนยิงทำลายสิ่งกีดขวาง |
| `game-19-cashier` | Cashier (พนักงานแคชเชียร์) | Calculation (การคำนวณ) | คิดเงินรวมสินค้า ใส่ส่วนลดคูปอง และทอนเงินจากลิ้นชักชำระเงิน | เกมฝึกการคำนวณเงินและการใช้งานคณิตศาสตร์ในชีวิตประจำวัน (Financial Math & Working Memory) ผู้เล่นรับบทเป็นพนักงานแคชเชียร์ที่ต้องรวมราคาสินค้าบนสายพาน หักส่วนลดจากคูปอง และหยิบแบงก์กับเหรียญจากลิ้นชักทอนเงินคืนลูกค้าให้ถูกต้องแม่นยำ |
| `game-20-boxcounting` | Box Counting (นับกล่องสามมิติ) | Visual (มิติสัมพันธ์สามมิติ) | นับจำนวนกล่องสี่เหลี่ยม 3 มิติทั้งหมดที่ซ้อนทับกันอยู่ รวมถึงกล่องที่ถูกบดบัง | เกมฝึกการจินตนาการมิติสัมพันธ์สามมิติและการนับแบบมีระบบ (3D Spatial Visualization & Mental Rotation) ผู้เล่นต้องมองภาพกลุ่มกล่องสี่เหลี่ยม 3 มิติที่วางซ้อนกัน แล้วคำนวณนับจำนวนกล่องทั้งหมดที่มีอยู่ในโครงสร้าง รวมถึงกล่องที่ซ่อนอยู่ใต้ชั้นบน |
| `game-21-parking-jam` | Parking Jam (เลื่อนรถออกจากลาน) | Planning (การวางแผนและแก้ปัญหา) | เลื่อนรถยนต์คันต่างๆ ในลานจอดรถเพื่อเปิดทางให้รถเป้าหมายขับออกจากลานได้ | เกมปริศนาขยับบล็อกเลื่อนรถออกจากลานจอด (Spatial Block Slider Puzzle & Logical Planning) ผู้เล่นต้องวางแผนย้ายรถยนต์คันอื่นๆ ที่จอดขวางทางเดินไปข้างหน้าหรือถอยหลัง เพื่อเปิดเส้นทางให้รถเป้าหมายสามารถขับเคลื่อนออกจากประตูทางออกลานจอดรถได้สำเร็จ |
